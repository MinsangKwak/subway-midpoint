## 브라우저에서 확인한 흐름

Playwright와 Chromium Headless Shell로 실제 React 앱을 실행했습니다. 외부 지도 SDK를 대체하거나 지도 타일을 합성하지 않았습니다.

- 키 없이 검색·계산·결과 카드를 사용할 수 있는지 확인
- 금정·강남을 자동완성에서 Enter로 선택하고 계산
- 선바위 1순위와 대안 후보 3개 표시 확인
- 두 번째 후보 선택 시 `aria-selected` 변경 확인
- 출발역 검색어 변경 시 이전 결과 제거 확인
- 390×844 모바일에서 하단 패널 표시 확인
- 시스템 다크 테마 화면 확인
- 위 실행 중 브라우저 `pageerror` 없음 확인

[데스크톱 결과](images/planner-result.png)는 금정·강남 입력, [모바일 화면](images/planner-mobile.png)은 출발역을 서울대입구·강남으로 바꾼 뒤 캡처했습니다. 표시 시간은 앱의 추정값이며 실제 운행시간을 검증한 결과는 아닙니다.
